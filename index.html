⚠️ Alpha Software Warning
This application is currently in alpha stage and the exported SVG shapes have not been verified to work using a laser cutter. (this is planned soon) Multiple cardboard and handcut thin wood models have been built by hand using the planner listed dimensions and cut points.

Please verify all measurements and cut patterns in the SVG file; you will need to rearrange the panels to fit on the material of your choosing anyway in a vector drawing program. Use at your own discretion and always double-check exported files. Have fun!

ℹ️ Quick Note
Also, please note that the planner is currently meant for building cases using Tiptop ZRails; I am currently working on adding support for Synthrotek Rails, but have not yet implemented it.
